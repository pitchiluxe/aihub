# AIHub — The Homepage of Artificial Intelligence

<p align="center">
  <img src="docs/images/dashboard.jpg" alt="AIHub Dashboard" width="100%" />
</p>

> **AIHub is the ultimate AI intelligence platform** — the central destination for AI news, model discovery, tutorials, agent development, prompt engineering, automation workflows, research tracking, and AI education. Think of it as the **Bloomberg Terminal, GitHub, Obsidian, Product Hunt, and Google News for Artificial Intelligence** combined into a single modern platform.

---

## 🎯 Mission

AIHub is **not another AI chatbot**. It's a real-time AI knowledge hub where users can:

- 📰 **Discover breaking AI news** across 15+ categories (OpenAI, Anthropic, Google, Meta, xAI, Mistral, DeepSeek, Open Source, Research, Robotics, Startups, Agents, Prompt Engineering)
- 🤖 **Discover & compare AI models** — benchmarks, pricing, context windows, use cases, leaderboards
- 📚 **Explore research papers** with AI summaries, visual breakdowns, citation graphs, and topic clustering
- 🎓 **Learn AI development** through structured tutorials (Prompt Engineering, Agent Development, RAG, MCP, LangGraph, CrewAI, AutoGen, Ollama, OpenRouter, Fine-tuning, AI App Development)
- 🤖 **Build & interact with AI agents** — 7 specialized AI experts (News Analyst, Model Expert, Agent Builder, Prompt Engineer, Workflow Architect, Research Assistant, Startup Advisor, Coding Mentor, Automation Specialist)
- 🔍 **Search AI-only content** — a dedicated "Google for AI" with instant results, topic filters, AI summaries, and related topics
- 🧠 **Explore the AI knowledge graph** — an Obsidian-inspired interactive D3 force-directed graph with zoom, pan, clustering, backlinks, bidirectional linking, and relationship discovery
- 📈 **Track AI trends** — heat maps, charts, timelines, trend graphs for topics, companies, models, tools, and frameworks
- 🛠️ **Build AI workflows** — n8n-inspired marketplace with templates, diagrams, and tutorials for agent workflows, RAG systems, and business automations
- 🤝 **Join the community** — discussions, weekly AI recaps, model/tool reviews, best prompts, best workflows

## 🚀 Getting Started

### Prerequisites
- Node.js 20+
- npm / pnpm / yarn / bun

### Installation

```bash
# Clone the repository
git clone https://github.com/pitchiluxe/aihub.git
cd aihub

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Edit .env.local with your API keys

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

### Environment Variables

```env
# AI Providers
OPENROUTER_API_KEY=your_openrouter_key
OLLAMA_BASE_URL=http://localhost:11434

# Database
DATABASE_URL=postgresql://...
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_key

# Caching
REDIS_URL=redis://...

# Analytics
NEXT_PUBLIC_VERCEL_ANALYTICS_ID=your_id
```

## 🌟 Key Features Deep Dive

### 🧠 Knowledge Graph (Obsidian-Inspired)
Built with **D3.js force-directed graph**:
- Interactive nodes & edges representing AI concepts
- Zoom, pan, drag, clustering
- Bidirectional linking (wiki-style `[[links]]`)
- Backlinks panel
- Graph filtering by category, connection strength, time
- Relationship discovery: `OpenAI → GPT-5 → Reasoning Models → Agents → MCP → AI Automation`

### 🤖 7 Specialized AI Agents
Each agent is an AI expert with system prompts tailored to their domain:
1. **AI News Analyst** — Breaking news analysis, trend detection
2. **Model Expert** — Benchmarks, comparisons, recommendations
3. **Agent Builder** — Step-by-step agent development guidance
4. **Prompt Engineer** — Prompt optimization, templates, techniques
5. **Workflow Architect** — n8n-style automation design
6. **Research Assistant** — Paper summaries, literature reviews
7. **Startup Advisor** — AI startup strategy, funding, GTM

### 🔍 AIHub Google (AI-Only Search)
- Semantic search across AI news, research, models, tutorials, companies
- AI-generated summaries for each result
- Topic filters & related topic suggestions
- Real-time indexing of AI content sources

### 📈 Trends & Analytics
- Heat maps of trending topics/companies/models
- Time-series charts of mention velocity
- Leaderboards (models, frameworks, companies)
- Market mover detection
